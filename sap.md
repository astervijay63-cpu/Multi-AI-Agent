# Statistical Analysis Plan (abridged)

Primary endpoint: change from baseline in HbA1c at Week 24, MMRM.
Safety analyses: treatment-emergent adverse events (onset on or after first dose), serious adverse events, liver safety (Hy's law screen per protocol §7), vital signs.
Data cuts: weekly incremental cuts; derived variables (treatment-emergent flag, visit windows) are re-derived at each cut under the protocol version in force.
Note: amendment 3 changes the prohibited-medication list; derived deviation flags computed before amendment 3 must be recomputed.
